# 端末間同期のセットアップ（所要 約10分・1回だけ）

スマホとPCで学習記録が分かれてしまう問題を解消する。設定するまでは今までどおり
端末内（localStorage）だけに保存され、アプリは完全に動く。設定した瞬間から同期が有効になる。

## 何が同期されるか

履歴（history）・できるようになったこと（wins）・連続日数・自己ベスト・ラチェット目標・
ペーサー速度・視幅・当日セッション・**既読本文（seenPassageKeys）**・わかりにくい報告・
週次目標・語彙帳・持ち帰り・アンカー転移履歴 — つまり学習状態のすべて。

## なぜこの方式か

| 論点 | 採用 | 理由 |
|---|---|---|
| 認証 | Supabase Auth のメールOTP（6桁コード） | パスワード管理が不要。スマホでも同じメールを打つだけ。Claude側もユーザー側も秘密を保持しない |
| 保護 | Row Level Security | anon key は公開前提の鍵。RLSで「自分の行だけ」に限定するので、鍵が公開リポジトリにあっても他人のデータは読めない |
| 保存形式 | 1ユーザー1行の JSONB | 学習状態は常に一括で読み書きするため、正規化してもコストしか増えない |
| 競合解決 | クライアント側のフィールド別マージ | 「後から書いた方の勝ち」にすると、スマホで進めた分がPCの同期で消える。集合はunion・記録はmax・設定は更新時刻で解決する |
| 排他 | rev による楽観的ロック | pull と push の間に他端末が書いた場合を検知して、再pull・再マージしてから書く |

## 手順

### 1. Supabase プロジェクトを作る

1. https://supabase.com にサインイン → **New project**
2. 名前は任意（例 `sokugan`）。リージョンは `Northeast Asia (Tokyo)` を選ぶと速い
3. データベースのパスワードは生成されたものを保管（アプリでは使わない）

### 2. テーブルとRLSを作る

1. 左メニュー **SQL Editor** → **New query**
2. このリポジトリの `supabase/schema.sql` の**全文**を貼って **Run**
3. 成功したら、末尾のコメントにある確認クエリを実行して
   `rowsecurity = true` とポリシー4件を確認する

### 3. メールログインを有効にする

1. 左メニュー **Authentication** → **Sign In / Providers**
2. **Email** を有効にする
3. **Confirm email** はオンのまま。**Enable email OTP**（6桁コード）を有効にする
4. 無料枠の送信メールは1時間あたりの上限が小さい。自分専用なら十分だが、
   届かないときは Authentication > Rate Limits を確認する

### 4. アプリに公開鍵を設定する

1. 左メニュー **Project Settings** → **API**
2. **Project URL** と **anon public** キーをコピー
3. リポジトリの `sokugan-config.js` を編集:

```js
window.SOKUGAN_CONFIG = {
  supabaseUrl: "https://xxxxxxxxxxxx.supabase.co",
  supabaseAnonKey: "eyJhbGciOi..."
};
```

4. commit して push（GitHub Pages に反映される）

> **service_role キーは絶対に置かない。** RLSを迂回できる鍵で、公開すると全ユーザーの
> データが読み書きできてしまう。`sokugan-config.js` に入れてよいのは anon public のみ。
> QAハーネスの F14 がこれを機械的に検査している。

### 5. 両方の端末でログインする

1. アプリを開く → 下部ナビの **記録** タブ → 「端末間同期」カード
2. メールアドレスを入れて「コードを送る」→ 届いた6桁を入力して「ログイン」
3. 最初にログインした端末の記録がクラウドへ移行する（**既存データは消えない**）
4. もう一方の端末でも同じメールでログインすると、両方の記録が結合される

## 動作の確認

- ホーム最下部に `✅ 同期済み HH:MM` が出る
- 機内モードにしても練習でき、`⚠ オフライン（未送信あり）` に変わる。
  オンラインに戻すと自動送信される
- スマホで1セッション、PCで1セッション行って両方に2件並べば競合マージが効いている

## トラブル

| 症状 | 対処 |
|---|---|
| 「同期未設定」のまま | `sokugan-config.js` の2値が空。push後にPWAを再読み込み（sw.jsのキャッシュ更新は自動） |
| コードが届かない | 迷惑メールを確認。Supabase の Auth > Rate Limits で送信上限に達していないか確認 |
| 「再ログインが必要です」 | リフレッシュトークンが失効。ログアウト → もう一度メールでログイン |
| 「他端末と競合中」 | 両端末が同時に書いた場合。もう一度「今すぐ同期」を押す（3回まで自動再試行済み） |

## やめるとき

`sokugan-config.js` の2値を空に戻せば同期は止まり、localStorage単独に戻る。
学習データは各端末に残る。クラウド側を消すなら Supabase の Table Editor で
`sokugan_state` の自分の行を削除する。
